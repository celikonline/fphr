**Akışlar**
1. Davet: çalışan kartı → üç nokta → **Davetiye gönder** → **Evet** → e-posta → bağlantıdan parola oluştur → giriş; toplu: **Çalışanlar → Toplu işlemler → İşlem seç → Giriş bilgilerini gönder** [part8 #18, #19].
2. Talep → onaycıya e-posta + ana sayfa → onaycı ana sayfadan veya e-postadan **Onayla/Reddet** → talep sahibine e-posta → durum **Kendi hesabım > Ödemeler** (avans/harcama) veya İzinler'de izlenir [part8 #13, #27, #33].
3. Yönetici izin ekle: kart → İzin → İşlemler → **İzin ekle** → tür/tarih → **Onay sürecine dahil etme** → **Çalışanı bilgilendirme e-postası gönder** → Kaydet [part8 #20].
4. Vardiya: haftalık plan → Not → Tekrarla → Kaydet → çalışanlara e-posta [part8 #27].
5. Rapor: Raporlar → filtre → oluştur → "hazırlanması 1 dakika sürebilir" → üç nokta → PDF/Excel indir; aynı dosya e-posta ile gelir [part1].
6. Yardım Merkezi: sol alt **Destek** → **Yardım Merkezi** → anahtar kelime → makale (video/GIF) [part8 #6].
7. Desteğe bağlan: **Destek → Desteğe bağlan** veya **Hesabım → Destek → Desteğe bağlan** → canlı destek [part8 #30; part1].
8. Mobil talep: **+** → tür → kısa form → **Devam/Sonraki** → **Gönder** → **Tamam** [part1 mobil].
9. Mobil harcama: fiş fotoğrafı çek → OCR alanları doldurur → düzelt → gönder [part1 mobil].
10. Erişim ayarları: Ayarlar → Sistem ayarları → Erişim ayarları → anahtarlar → **Kaydet** → menü ve ana sayfa anında değişir [part8 #10].

**Alanlar**
- **Bordro parametresi** (çalışan, `EmployeePayrollProfile`, sürümlü): SGK işyeri (Company/Location sicil), ücret esası (**Ödeme düzeni**: Aylık/Günlük/Yıllık/Haftalık/Saatlik [Ekranda: part1 özlük şablonu]), SGK statüsü (normal / emekli-SGDP / stajyer / çırak / yabancı), teşvik kanunu kodu [Aday], yemek ödemesi varyantı + günlük tutar, yol yardımı varyantı (nakit / kart / servis), ödeme yöntemi + banka hesabı (**Banka hesap tipi** Çek/Vadeli/Vadesiz/Diğer + IBAN [Ekranda: part1 özlük şablonu] → `Employee.BankAccount`, 11.3.3), hastalık günü kesinti kuralı, dış bordro personel kodu. Engellilik derecesi, emeklilik, önceki işyeri matrahı planda mevcut alanlardan okunur.
- **Maaş bloğu** (özlük içe aktarım şablonu) [Ekranda: part1]: Maaş geçerlilik tarihi, Maaş, Para birimi, **Maaş türü** (Net/Brüt), **Ödeme düzeni**, **Yol yardımı**, **Yemek yardımı** → `SalaryHistory{Gross/Net, PayPeriod, EffectiveFrom}` (11.3.3) + `EmployeeRecurringPayItem(TRANSPORT_*/MEAL_*)` otomatik üretimi + `EmployeePayrollProfile.WageBasis`. Döviz maaş: hesap TL'de, kur `LegislationParameter`/TCMB (Expense'teki kur servisi ortak) [Aday].
- **Yemek ödemesi varyantı** [Ekranda: part1 s.385–390]: nakit / ayni (işyerinde yemek) / yalnız yemek kartı / yemek+market kartı; "gerekli parametrelerin tanımlanması hesap için yeterli" → varyant + günlük tutar (+ kart sağlayıcısı, Multinet entegrasyonu ile ilişki → 3.19).
- **FM → ödeme** [Ekranda: part8 #8]: **çarpan** (birden fazla seçenek; liste söylenmedi), **net veya brüt** tutar, açıklama; kayıt "Ödemeler"e "fazla mesai" türüyle düşer.
- **Sendika / TİS** [Mevzuat: part3 #2]: sendika (ad, iş kolu), üyelik tarihi, işverene bildirim tarihi, TİS'ten yararlanma tipi (üye / dayanışma aidatlı / sendika onaylı / kapsam dışı), aidat kuralı; TİS (tür: işyeri / işletme / grup, süre 1–3 yıl, yürürlük başlangıç-bitiş, geriye dönük başlangıç, hükümler: ücret zammı, sosyal haklar, çalışma süreleri).
- **Mahkeme kararı** [Mevzuat: part5 #3; planda icra/nafaka var]: tür (icra / nafaka / işe başlatmama / kötü niyet / ayrımcılık / sendikal / md.30 / md.31), mahkeme + dosya no, karar tarihi, tutar veya formül (ör. "ihbar süresi × 3", "4–8 aylık ücret"), ücret esası (çıplak / giydirilmiş), mahsup edilecek önceki ödemeler, belge.
- **İşyeri devri** [Mevzuat: part3 #2]: devir tarihi ve devir anındaki ücret anlık görüntüsü (Organization/Employee'de planlı, 3.2) → `TerminationCalculation.TransferSegments`.

**İş kuralları ve hesaplama**
- **Parametre tabanlı hesap** [Ekranda: part1]: kullanıcı mevzuat bilmez; profil + kalem tipi → kural. SenseİK'da zaten `PayItemType` kural + `LegislationParameter`; ek olarak profil seviyesinde varyant seçimi (yemek, yol, SGK statüsü, teşvik) hesap motoruna girer. Tüm sayısal değerler `LegislationParameter`; kodda sabit yok.
- **Yemek varyant kuralları** [Aday — öneri, 11.6 ve mali müşavirle doğrulanmalı]: ayni → SGK ve GV matrahı dışında (tutarsız, bilgi kalemi); nakit ve yalnız yemek kartı → fiilen çalışılan gün × günlük istisna (`Meal.IncomeTax.DailyExemption`) GV'den, günlük brüt asgari ücret × `Meal.Sgk.DailyExemptionRate` SGK'dan istisna, aşan kısım matraha; yemek+market kartı → `Meal.MarketCard.ExemptionApplies=false` ise tamamı matraha. İstisna gün sayısı puantajdan (`TimesheetLine.WorkedDays`).
- **Değişti mekanizması** [Ekranda: part1 s.397–402] — SenseİK tek modül olduğundan "eş zamanlı çekme" yerine: hesaplama anında Contracts okuma servislerinden (`ITimesheetReadService`, `ILeaveReadService`, `ISalaryReadService`, `IAdjustmentReadService`) alınan girdiler `Payslip.InputSnapshot` + `InputHash` olarak saklanır. (a) Olay güdümlü: `Attendance.TimesheetLineChanged`, `Leave.LeaveApproved/Cancelled`, `Leave.OvertimeConvertedToPay`, `Employee.SalaryChanged`, `Expense.AdjustmentPosted`, `Payroll.RecurringItemChanged/ProfileChanged`, `LegislationParameterChanged` → ilgili açık dönem `PayslipDirtyFlag{EmployeeId, Reasons[], SourceEventId}`. (b) Zamanlı: `ChangeDetectionRun` (Hangfire, `Payroll.ChangeDetection.IntervalMinutes`, varsayılan 5) açık dönemlerde canlı hash ≠ snapshot hash olan satırları bayraklar (event kaçırma sigortası). (c) Yeniden hesap yalnız bayraklı satırları hedefler (`RecalculateDirty`), `RecalculateAll` tümünü; başarılı hesap bayrağı `ClearedByRunId` ile kapatır. (d) Dönem Approved/Paid/Locked ise bayrak yazılır, hesap yapılmaz; UI "kilitli dönemde değişiklik var → Supplementary run" uyarısı. (e) Bayrak nedenleri kullanıcıya kaynak anahtarıyla gösterilir (`payroll.dirty.reason.timesheet` …).
- **Hesap turnusolu** [Ekranda: part1 s.406–412]: her hesapta `PayslipCalculationTrace` üretilir; adımlar plandaki brüt→net akışını birebir izler: `DAYS` (PayableDays, DailyRate, HourlyRate), `EARNINGS` (kalem kalem), `SGK_BASE` (istisna düşümü, taban/tavan), `SGK_EMPLOYEE`, `UNEMP_EMPLOYEE`, `GV_BASE`, `CUMULATIVE_BASE` (önceki aylar + önceki işyeri), `INCOME_TAX` (dilim dökümü), `MINWAGE_EXEMPTION_GV`, `STAMP_TAX`, `MINWAGE_EXEMPTION_DV`, `DEDUCTIONS` (avans, icra 1/4, nafaka, sendika/dayanışma, BES, disiplin), `NET`, `EMPLOYER_SGK/DISCOUNT/UNEMP`, `EMPLOYER_COST`, `NET_TO_GROSS_ITER` (iterasyon listesi). Her adım `{Order, Code, TitleKey, Inputs, Formula, Output, ParameterRefs[{Key, Value, ValidFrom}], RuleRefs[]}`; `ParameterSnapshotId` `PayrollRun.ParameterSnapshot`'a bağlanır. Sürümler arası fark görünümü ("önceki hesaba göre değişen adımlar"). PDF `Payroll.Trace.AutoGeneratePdf` açıksa toplu üretilir, yoksa istek anında; saklama `Payroll.Trace.RetentionYears`.
- **Çarşaf** [Ekranda: part1 s.403–405]: kolon kataloğu = sabit kolonlar (çalışan, birim/`OrgUnit` türleri, maliyet merkezi, SGK işyeri, SGK gün, eksik gün + kod, teşvik kanunu, sendika) + tenant'ın aktif `PayItemType` listesinden dinamik pivot kolonları + matrah/vergi/kesinti/net/işveren maliyeti; birden fazla dönem seçilebilir; grid standardı (sunucu taraflı filtre/sıralama), Excel'de autofilter, dondurulmuş başlık, toplam satırı; kayıtlı kolon setleri.
- **FM ödemesi** [Ekranda: part8 #8]: net girilen tutar → kalem bazında brütleştirme (`GrossUpItem`: kalemin SGK/GV/DV uygulanabilirliğine göre iterasyon; bordro geneli net→brüt döngüsüne dahil edilir, çift brütleştirme yok); brüt girilen tutar doğrudan kalem; çarpan yalnız bilgi ve PayItemType eşlemesi için (saat × saat ücreti × çarpan hesabı Leave'den gelen tutarla çelişirse uyarı). Kolay İK'da dönüşüm onaydan sonra yönetici tarafından; plandaki `OvertimeRequest.Compensation` talep anında → 11.3.5 kararı; Payroll yalnız `Leave.OvertimeConvertedToPay{OvertimeRequestId, Hours, Multiplier, Amount, AmountBasis}` event'ini tüketir.
- **Sendika / TİS** [Mevzuat: part3 #2]: aidat `DuesRule` (brüt %, sabit, günlük yevmiye) ile `UNION` kalemi; üye olmayanlar için `SOLIDARITY_DUES`; kesinti başlangıcı = `NotifiedToEmployerAt` sonrası ilk dönem; TİS hükümleri (`Terms`) çalışanlara `Source=CollectiveAgreement` sabit kalem üretir (ücret zammı → `SalaryHistory` önerisi, 11.3.3/3.14); TİS görüşmeleri uzayıp yürürlük geriye uzanınca (`RetroactiveFrom`) `Supplementary` run: geçmiş dönemler yeni hükümlerle gölge hesap → fark `TIS_RETRO_DIFF` kalemi, kümülatif GV matrahı ve SGK tavanı ödeme ayında yeniden değerlendirilir (kural 11.6); TİS ile bireysel sözleşme çelişirse işçi lehine hüküm (`Term.ApplyIfMoreFavorable`: kalem bazında max). Sendika yöneticiliği → iş sözleşmesi askıda: tahakkuk durur (`Employee.Status=Suspended` → 11.3.3).
- **Kıdem / ihbar** [Mevzuat: part3 #2, part5 #3]: işyeri devrinde kıdem bölüşümü (devreden: kendi dönemi × devir tarihindeki ücret; kalan devralan; ihbar tamamen devralan) → `TransferSegments`; boşta geçen süre ücreti (≤4 ay) SGK günü ve kıdeme eklenir → ek APHB satırı; önceden ödenen kıdem/ihbar mahsubu; iflas halinde 1 yıl içindeki ücret/prim/ikramiye 1. sıra alacak → yalnız rapor (alacak dökümü), motor değişikliği yok; kullandırılmayan iş arama izni ücreti çıkış hesabına kalem (`JOB_SEARCH_LEAVE_PAY`) [Mevzuat: part2 #3]. Kıdem/ihbar/tazminat tutarlarının SGK/GV/DV uygulanabilirliği 11.6'da; motor `WageBasis(Bare/Dressed)` parametresini kalem bazında alır.
- **Ücret esası** [Mevzuat: part2 #3]: maktu (aylık) ücrette hastalık izni günleri ücretten ve SGK'dan kesilmez; günlük/saatlik ödemede kesilir → `WageBasis` + `SickDaysReducePay`; SGK raporlu gün (`SICK_EMPLOYER_2D`, `SGK_REPORT_DIFF`) kuralları planda mevcut, profil bayrağı bunları şartlar. Askerlik izni ücretsiz, işveren isterse ücret ödeyebilir → elle `EmployeeVariablePayItem` (kural yok) [Mevzuat: part2 #3].
- **Kısa çalışma / ücretsiz izin** [Müşteri: part8 #27]: kısa çalışma ödeneği devletçe ödenir, işveren çalışılan günleri öder → çalışılmayan günler SGK eksik gün kodu (`MissingDayReasons` parametrik; kısa çalışma ve pandemi ücretsiz izin kodları 11.6); haftada belirli günler ücretsiz izin → puantajdan eksik gün; "evden çalışma" izin türü ücretli ve eksik gün değildir, "bordrosu düzenli işlenir" → `LeaveType.IsPaid=true && SgkMissingDayCode=null` olan türler Payroll'a girmez.
- **Ön kontrol listesi** (hesap öncesi uyarılar; Kolay Bordro'nun "hatasız hesaplama" iddiasına karşılık) [Aday — öneri; part5 #11 "eksik cetvel → hatalı bordro"]: puantaj kilitli mi, eksik gün kodu boş mu, IBAN/banka hesabı var mı, profil geçerli mi, asgari ücret altı brüt, tavan üstü SGK, kümülatif matrah sıçraması, bayraklı satır varken onaya gönderme.
- **Evrak** [Mevzuat: part5 #7]: imzalı bordro/ücret pusulası ve maaş zammı/terfi yazısı özlük dosyasında; ücret kesme cezası gerekçeli belgeyle → `DISCIPLINE` kalemi belge zorunlu (`PayItemType.RequiresDocument`); kıdem ve ihbar tazminatı bordroları çıkışta ayrı belge.
- Ürün konumlandırması [Müşteri: part6 #1]: "doğru insana doğru maaşın doğru şekilde ödenmesi; işgören tarafı + İş Kanunu tarafı" — ek gereksinim yok.

**Akışlar**
1. **Profil tanımı**: işe girişte `EmployeeHired` → varsayılan profil (`Payroll.Meal.DefaultVariant`, `WageBasis` = SalaryHistory.PayPeriod) → İK/bordro uzmanı düzenler (`payroll.profile.manage`); değişiklik yeni sürüm (ValidFrom) → açık dönem bayraklanır.
2. **Dönem hesabı**: Dönem aç → girdi anlık görüntüsü → hesapla → her satır için turnusol → uyarı listesi → **Değişenler** boşken Submit (Workflow `PayrollPeriodApproval`, planda).
3. **Değişti**: kaynak event / 5 dk mutabakat → bayrak → **Değişenleri yeniden hesapla** → turnusol yeni sürüm → fark görünümü.
4. **Yayın ve tebliğ**: MarkPaid → e-pusula yayını → `PayslipDelivery` (web/mobil/e-posta; KEP [Aday]) → çalışan "Görüntüledim / Onaylıyorum" (`SignatureRequest` Click/Otp) → imzalı PDF özlük dosyasına (→ 11.3.9); `Payroll.Payslip.RequireAcknowledgement` açıksa hatırlatma job'ı.
5. **Kilit ve çıktı**: Lock → çarşaf, icmal, APHB/MUHSGK, banka dosyası, muhasebe fişi (planda) + dış bordro aktarım dosyası (profil varsa).
6. **Supplementary**: kilitli dönemde bayrak / TİS geriye dönük / mahkeme kararı → fark bordrosu; turnusolda "fark hesabı" adımı.
7. **FM → ödeme** (Leave tarafı → 11.3.5): onaylı FM → Ödemeye çevir (çarpan, net/brüt) → `Leave.OvertimeConvertedToPay` → `EmployeeVariablePayItem(Source=Overtime)` → çalışan kartı **Ödemeler** listesinde (→ 11.3.8) → dönem hesabında kalem.
8. **Dış bordro** (Payroll modülü kapalı veya "master" dış sistem): Ayarlar > Dış bordro aktarım profili → dönem/tarih aralığı seç → `ExternalPayrollExportRun` (async, Documents'a dosya, SignalR bildirimi) → indir / SFTP [Aday]; içerik: puantaj satırları (gün, eksik gün kodu, FM saatleri çarpan bazında), ek ödeme/kesinti kalemleri (kod, tutar, net/brüt), maaş değişiklikleri, işe giriş/çıkış, izinler; çalışan eşleme anahtarı `EmployeeNumber` veya `ExternalPayrollCode`.

**Roller ve yetkiler**

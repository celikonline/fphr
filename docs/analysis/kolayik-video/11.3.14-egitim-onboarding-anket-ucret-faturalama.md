- Anket [Aday]: eNPS skoru = %destekleyici − %tavsiye etmeyen (transkriptte yalnız kategoriler var; formül standart eNPS varsayımı, doğrulanmalı); anonim kampanyada `SurveyResponse.RespondentEmployeeId` boş, yalnız boyut anlık görüntüsü (`OrgUnitId, LocationId, Gender?, TenureBucket, AgeBucket`) tutulur; kırılım sonucu yalnız yanıt sayısı ≥ `Survey.AnonymityMinResponses` (varsayılan 5, kiracı ayarı; Performance'taki "peer < 3 ise anonim" kuralıyla aynı ilke) ise gösterilir; davet-yanıt bağı tek yönlü token ile koparılır (kimin yanıtlamadığı bilinir, ne yanıtladığı bilinmez); `AnonymityMode(Forced/Optional/Named)`; tekrar RRULE; katılım oranı = yanıt / davet; "sonuçları çalışanlarla paylaş" → Announcements'a "Duyuru olarak paylaş" kısayolu; istek kutusu anonim gönderimde IP/kimlik saklanmaz.
- Yan haklar [Aday]: uygunluk kuralı (birim/pozisyon/kıdem/istihdam tipi) ile kayıt önerisi; işveren/çalışan payı; vergilendirme `PayItemTypeCode` bağıyla Payroll'a (istisna tutarları `LegislationParameter`); kullanım takibi (eğitim bütçesi, yemek kartı yükleme, danışmanlık seans sayısı) `BenefitUsage`; `EmployeeTerminated` ile kayıt kapanır; ÖSS bağımlı kapsamı `Dependent` kaydına bağlanır (→ bkz. 11.3.3).
- Ücret: zam uygulandığında "maaş zammı / terfi yazısı" belgesi üretilir [Mevzuat]; toplam ödül = brüt ücret + işveren yan hak maliyeti [Aday].
- Faturalama: Hesap sahibi / Yönetici farkı yalnız Ödeme bilgileri sayfası [Ekranda]; erişim yönü çelişkili (Açık noktalar); ek ürünler satış/müşteri başarı kanalıyla açılıyor [Müşteri]; ATS ayrı hesap ve Google ile giriş (→ bkz. 11.3.11); Poma raporlarını test etmek Kolay İK müşterisi için "birkaç dakika" (veri zaten sistemde) [Müşteri] → analytics modülü açıldığında geriye dönük KPI hesabı (→ bkz. 11.3.12).

SenseİK: çalışan grid toplu aksiyonu `assign-work-schedule`, çalışan kartı "Çalışma takvimi" alanı + tarihçe.

**Alanlar**
- Çalışma takvimi: **Ad** (örnekler: "Genel çalışma tablosu", "Kısa çalışma takvimi B", "Satış", "Yeni takvim"); **çalışma günleri** (gün bazlı seçim; örn. yalnız Pzt-Sal-Per-Cum; veya Perşembe tatil + Cumartesi çalışma); gün bazlı **başlangıç/bitiş** (09:00–18:00; Salı 15:30 bitiş); **mola** (12:30–13:30); izin sayım kuralı **"Pazartesi'den Cuma'ya izin alırsa Cumartesi'yi ekle"**; varsayılan işareti. → `WorkSchedule{Name, IsDefault, IsActive, IncludeSaturdayWhenFullWeek}` + `WorkScheduleDay{DayOfWeek, IsWorkingDay, Start, End, BreakStart, BreakEnd}`; `WeeklyMinutes`/`DailyMinutes` hesaplanır.
- Takvim ataması: çalışan(lar), takvim, atama tarihi (= geçerlilik başlangıcı). → `EmployeeWorkScheduleAssignment{EmployeeId, WorkScheduleId, EffectiveFrom, Source(Manual/Bulk/Hire), AssignedByUserId}`.
- Puantaj hücresi: planlanan saat (mavi), gerçekleşen saat (yeşil), giriş/çıkış saatleri, çipler, öneriler. Örnekler [Ekranda, part1]: 8 s planlanmış / 9 s çalışılmış, 18:00 yerine 19:00 çıkış → **Geç çıkış** + **Fazla çalışma**; 7 s çalışılmış, 1 saat erken çıkış → **Az çalışma**. → `AttendanceDay{PlannedMinutes, WorkedMinutes, BreakMinutes, NetMinutes, LateMinutes, EarlyLeaveMinutes, LateLeaveMinutes, OvertimeMinutes, MissingMinutes, Anomalies(flags), ResolutionState, OverrideWorkedMinutes, OverrideReason, WorkLocation, CompensatoryMinutes}`.
- PDKS import şablonu: kolon başlıkları videoda okunmuyor; veride çalışan adı + gün + giriş/çıkış saati var ("Normalde 18'de çıkması gerekirken 19'da çıkmış") → en az **Çalışan (Ad Soyad / Kimlik No)**, **Tarih**, **Giriş**, **Çıkış** [Aday; kolonlar doğrulanmalı]. Sonuç dosyası: yüklenen satırlar + durum + hata açıklaması kolonu; hata yoksa açıklama boş. → `AttendanceImportJob{SourceDocumentId, ResultDocumentId, TemplateVersion, TotalRows, ImportedRows, ErrorRows, Status, StartedAt, CompletedAt}`, `AttendanceImportRow{JobId, RowNo, EmployeeKey, EmployeeId?, Date, CheckIn, CheckOut, BreakMinutes?, Status(Imported/Error/Skipped), ErrorCode}`; hata metinleri kaynak anahtarlı (`attendance.import.error.employeeNotFound` vb.).
- Vardiya ayarları [Ekranda, part8 #27]: **Günlük çalışma süresi üst sınırı** (11 s varsayılan; örn. 6), **Tam zamanlı / Yarı zamanlı** ayrı sınır (yarı zamanlı 3 s), **Haftalık çalışma günü** (örn. 2), **Haftalık çalışma saati** (45; düşürülebilir), **Gece çalışması**, **Mola ayarları** (süre), **Otomatik kilitleme/kapatma**. → `ShiftSettings{Limits: {FullTime:{MaxDailyHours, MaxWeeklyDays, MaxWeeklyHours}, PartTime:{…}}, NightWork{Enabled, Start, End, MaxHours}, Break{MinMinutes, IsPaid}, AutoLock{Enabled, DayOfMonth, NotifyDaysBefore}, NotifyEmployeesByEmail}`.
- Vardiya kaydı: çalışan, gün, saat aralığı / vardiya tipi, **Not**, **Tekrarla** (hedef haftalar), durum (bekleyen / paylaşılmış), kilit. → `ShiftAssignment{EmployeeId, Date, ShiftTemplateId?, Start, End, BreakMinutes, IsNight, Note, Status(Draft/Published), PublishedAt, PlanLockId?}`.
- Müsaitlik: gün, saat aralığı, tür ("bugün çalışmak istemiyorum" / "haftalık iznimi kullanmak istiyorum"), not. → `EmployeeAvailability{EmployeeId, Date, Start?, End?, Kind(Unavailable/WeeklyRestRequest), Note, Status(Active/Cancelled)}`.

**İş kuralları ve hesaplama**
- Plan vs gerçekleşen karşılaştırması gün bazında; PDKS verisi olmayan gün "çalışılmamış" uyarısı taşır; import sonrası hafta yeniden hesaplanır [Ekranda, part1].
- Çip kuralları [Ekranda, part1]: gerçek çıkış > planlanan çıkış → **Geç çıkış**; çalışılan > planlanan → **Fazla çalışma**; çalışılan < planlanan → **Az çalışma**. Erken çıkış ayrı çip olarak görülmedi (1 saat erken çıkan çalışanda yalnız Az çalışma); geç giriş çipi görülmedi → `LateArrival`, `EarlyLeave` bayrakları SenseİK'da tutulur, UI'da çip olarak gösterimi kiracı ayarı [Aday].
- Öneri kuralı [Ekranda, part1]: Fazla çalışma → yalnız **Fazla mesai ekle** aktif, diğer aksiyonlar pasif; Az çalışma → **Çalışılan saat** veya **İzin talebi** ("mesai yok, çünkü az çalışma var"). SenseİK: `IAnomalyResolutionAdvisor` anomali → izinli aksiyon kümesi.
- Çözüm etkisi [Ekranda, part1]: FM eklenince Geç çıkış + Fazla çalışma çipleri kalkar; izin talebi eklenince Az çalışma çipi kalkar; hiç uyuşmazlık kalmayınca "haftalık puantaj tamamlanmış". SenseİK: `AnomalyResolution` kaydı + `AttendanceDay.ResolutionState`; hafta durumu projeksiyon; `TimesheetPeriod.Approve` öncesi tüm haftalar tamamlanmış olmalı (`Attendance.Timesheet.RequireAllWeeksCompletedBeforeApprove`, varsayılan açık).
- Yetkili (Owner/Manager) puantajdan izin eklerse onay sürecine girmeden **Onaylanmış** [Ekranda, part1] → bkz. 11.3.4 (`AutoApproveWhenCreatedByPermission`).
- FM tespiti → talep: Kolay İK öneri gösterir, otomatik talep açmaz [Ekranda, part1]; plandaki otomatik akış seçenek olarak kalır (`Attendance.Overtime.DetectionMode`). `Suggest` modunda `AttendanceOvertimeDetected` yayınlanmaz; çözümde `OvertimeRequest{Source=Attendance, Date, Minutes}` Leave.Contracts komutuyla açılır.
- Takvim ataması atama tarihinden itibaren geçerli; "bundan önceki çalışma biçimi değişmemiş olur, puantajında bu tarihten itibaren yeni takvim" [Ekranda, part8 #27]. SenseİK: `EmployeeWorkScheduleAssignment` tarihçesi; geçmiş `AttendanceDay` kayıtları yeniden hesaplanmaz; aynı tarihe ikinci atama önceki kaydı kapatır.
- İzin gün hesabı çalışanın takvimine göre (hafta tatili düşülür); Cumartesi kuralı takvim düzeyinde; türde "çalışma takvimini geçersiz kıl" işaretliyse takvim günü [Ekranda, part8 #31] → bkz. 11.3.5.
- Yöneticinin onay süreci dışında eklediği ücretsiz izin puantajda görünür; çalışan izinli olduğunu kendi puantajında görür [Ekranda, part8 #27]. SenseİK: `LeaveApproved` tüketicisi `AttendanceDay.LeaveTypeId` + `PlannedMinutes=0` (ücretsiz izin → TimesheetLine UnpaidLeave, SGK eksik gün → bkz. 11.3.7).
- "Evden çalışma" izin türü: ücretli, yıl içinde limitli (40 gün), takvim yılı bazlı, devretmez, açıklama zorunlu, takvimde gösterilir; "ne ücretsiz izin ne yıllık izin hakedişinden düşen, puantajı etkileyen bir izin" — iş güvenliği ve "kim evde/kim izinde" görünürlüğü için [Ekranda, part8 #27]. SenseİK: `LeaveType.AffectsTimesheet=false` → gün çalışılmış sayılır, `AttendanceDay.WorkLocation=Remote`.
- Kısa çalışma [Ekranda, part8 #27]: (a) haftada belli gün/saat çalışılacaksa departman veya çalışan bazlı kısa çalışma takvimi; (b) takvim korunup her hafta belirli gün ücretsiz izin türüyle ("Ücretsiz izin" ya da "Corona ücretsiz izin": ücretsiz, limitsiz, yarım gün hesaplama) takip; (c) vardiya modülünde limitleri düşürme ya da 45 s korunup gerçek saatlerin planlanması ve telafi. Kısa çalışma ödeneği başvurusunda puantaj kanıt olarak istenir [Müşteri, part8 #27].
- Vardiya limitleri [Ekranda, part8 #27]: mağaza müdürü/birim yöneticisi planlarken genel merkezin tanımladığı **üst sınırların üzerine çıkamaz**; günlük üst sınır, haftalık gün ve saat sınırı istihdam tipine göre (tam/yarı zamanlı). SenseİK: `AssignShift`/`RepeatShiftAssignments` komutlarında `ShiftLimitValidator` (hata kodları `attendance.shift.dailyLimitExceeded`, `weeklyHoursExceeded`, `weeklyDaysExceeded`, `leaveConflict`, `availabilityConflict`, `planLocked`); istihdam tipi `Employee.EmploymentType` (Çalışma şekli) → bkz. 11.3.3.
- Telafi çalışması [Ekranda, part8 #27] [Mevzuat]: "45 saati bırakıyorum ama gerçekte çalışmıyorum, ne kadar çalışırsam o kadar vardiya oluşturuyorum; işler normale döndükten sonra 4 ay içinde telafi çalışması yaptırabilir, bunları raporundan alabilirim". 4857 md.64: telafi süresi 2 ay (pandemi döneminde 4 aya çıkarıldı), günde en fazla 3 s ve günlük 11 s aşılmaz, telafi FM sayılmaz → `LegislationParameter.CompensatoryWorkWindowMonths`, `CompensatoryWorkMaxDailyHours` tarih aralıklı (doğrulanmalı).
- Plan kilidi [Ekranda, part8 #27]: aylık plan belirli tarihte otomatik kilitlenir ("26 Ağustos tarihinde kilitlenecek"); kilit sonrası vardiya değişikliği engellenir. SenseİK: `ShiftPlanLock` + `attendance.shift.unlock` ile istisnai açma (audit).
- Vardiya düzenleri (genel İK içeriği, part5 #5): ikili vardiya mola dahil 12 s, kanuni süre üstü FM %50; üçlü 3×8 s, ara dinlenmelerle haftalık 45 s aşılmaz; dörtlü 4×6 s; gece vardiyaları sağlık/güvenlik gibi rollerde zorunlu. SenseİK: seed şablonlar [Aday]; 12 s vardiyada 11 s günlük sınır uyarısı.
- Puantaj cetveli tanımı (genel İK içeriği, part5 #11): aylık; ayın her günü; hafta tatili ve resmi tatiller önceden işaretli; devamsızlık, raporlu gün, geç gelme, FM gün/saat alanları; PDKS (kart, parmak izi, retina) ile otomatik besleme; çalışma takvimi + izin + puantaj eşleştirmesi. SenseİK: `TimesheetLine` kolonları planla uyumlu; UI etiketi "Puantaj cetveli"; `AttendanceEvent.Source=Device` + `DeviceKind(Card/Fingerprint/Retina/Face)` [Aday].
- Esnek/hibrit [Müşteri, part3 #1; part5 #12]: 07:30–09:30 arasında başlanabilir, çıkış kayar; 3 gün ofis + 2 gün uzaktan; departman bazlı hibrit, %60 ofis hedefi, ölçüm %35–40. Kolay İK özelliği olarak doğrulanmadı → [Aday] `FlexStartFrom/To`, `WorkLocationPlan`.
- Vardiya planı e-posta ile çalışana gider; çalışan hangi saatlerde çalışacağını görür [Ekranda, part8 #27] → Notifications şablonu `shift.published` (e-posta + push; kiracı ayarı `Attendance.Shift.NotifyEmployeesByEmail`).

**Akışlar**
1. Haftalık puantaj kapatma [Ekranda, part1]: hafta seç → uyarılı hücreler → **Şablonu indir** → PDKS verisini şablona doldur → yükle → "Import tamamlandı" → sonuç Excel'ini indir (hatalı satırları düzelt, yeniden yükle) → sayfayı yenile → kalan uyuşmazlıkları hücre bazında öneriyle çöz (**Fazla mesai ekle** / **Çalışılan saat** / **İzin talebi**) → "hiç uyuşmazlık kalmamış, haftalık puantaj tamamlanmış". SenseİK devamı: ay sonunda `TimesheetPeriod` hesapla → onayla → kilitle → `TimesheetPeriodLocked` → Payroll (planda mevcut).
2. Çalışma takvimi tanımlama ve atama [Ekranda, part8 #22]: Ayarlar > Kurallar > Çalışma takvimleri → varsayılanı düzenle ya da **Yeni çalışma takvimi ekle** (ad, günler, saatler, kural) → Kaydet → Çalışanlar > Toplu işlemler → çalışanları seç → İşlem seç > Çalışma takvimi ekle → takvim seç → Kaydet → atama tarihinden itibaren puantaj yeni takvime göre.
3. Kısa çalışma senaryosu [Ekranda, part8 #27]: (a) "Kısa çalışma takvimi B"/"Satış" takvimi → departman filtresiyle toplu atama; (b) çalışan kartı > İzin > İşlemler > İzin ekle → ücretsiz izin türü, tarih aralığı, **Onay sürecine dahil etme** kapalı → Kaydet → puantaja yansır → Raporlar > İzinler'den kim kaç gün; (c) Vardiya yönetimi > Ayarlar'da limitleri düşür ya da 45 s koruyup gerçek saatleri planla → telafi raporu.
4. Vardiya planlama [Ekranda, part8 #27]: Ayarlar (limitler, gece, mola, otomatik kilit) → haftalık görünümde çalışan seç → vardiya gir → **Not** → **Tekrarla** (haftalar) → Kaydet → e-posta → aylık görünümde bekleyen/paylaşılmamış vardiyaları paylaş → kilit tarihine kadar düzenle → Raporlar: tarih aralığı → tüm çalışanlar → **İndir**; **Haftalık özet yazdır**.
5. Çalışan self-servis [Ekranda, part8 #3, #27]: **Müsait değilim** gir → planlayıcı görür → plan yapılır → e-posta → Vardiyam ekranında saatler; Uygulamalar > Puantaj'da ay içi toplam gün/saat.

# Kolay İK Bordro — Mevcut Ürünlerle İlişki Analizi

> Kaynaklar: `docs/analysis/kolayik-video/11.3.07-bordro.md`, `11.3.03/05/06/08/09`, `11.6-mevzuat-sorulari.md`, `kolayik.com/bordro-yazilimi`, kod: `src/Modules/Payroll/*`, `web/src/pages/payroll/*`, `apps/senseik-mobile/src/screens/app/PayrollScreen.tsx`.
> Tarih: 2026-09-17

## 1. Süreç haritası

```
Profil tanımı → Dönem aç → Girdi snapshot → Hesapla → Turnusol
  → Değişti bayrağı → Yeniden hesapla → Ön kontrol → Onay
  → E-pusula yayın/tebliğ → Kilit → Çıktılar
  → Supplementary / Dışa aktarım
```

Kolay İK'da bordro ayrı uygulamadır (**Kolay Bordro**, `Uygulamalar` menüsü, 2024 kapalı beta).
SenseİK'da tek modülde `*.Contracts` okuma + snapshot ile karşılanır.

## 4. Hesap motoru (`PayrollCalculator.Calculate`)

Girdi: `PayrollCalculationInput{GrossMonthlySalary, WorkedDays, CalendarDaysInMonth, MealVariant, MealDailyAmount, PriorCumulativeGvBase, AsOfDate, ExpenseReimbursement=0}`.

Mevzuat: `PayrollLegislationSnapshot{IncomeTaxBrackets[], SgkFloor, SgkCeiling, SgkEmployeeRate, UnemploymentEmployeeRate, SgkEmployerRate, UnemploymentEmployerRate, SgkEmployerDiscountRate, StampTaxRate, MinimumWageGross, MealIncomeTaxDailyExemption, MealSgkDailyExemptionRate, MealMarketCardExemptionApplies, AsOf}` — kodda sabit yok (ADR 0008).

Adımlar: `DAYS → EARNINGS → SGK_BASE=clamp(gross+mealSgkExcess) → SGK_EMPLOYEE → UNEMP_EMPLOYEE → GV_BASE → CUMULATIVE_BASE → INCOME_TAX (kümülatif dilim) → MINWAGE_EXEMPTION_GV (türetilmiş) → STAMP_TAX → MINWAGE_EXEMPTION_DV → DEDUCTIONS (=0, P3/P5) → NET (+nakit yemek +vergisiz masraf) → EMPLOYER_SGK/DISCOUNT(=0)/UNEMP → EMPLOYER_COST`.

Yemek kuralı:

- `None`: 0.
- `Cash / MealCardOnly`: günlük istisna aşımı matraha girer, tamamı nete ödenir.
- `InKind`: iki matrah dışı, nete eklenmez.
- `MealAndMarketCard`: taslakta tamamı matrahta (`ExemptionApplies=false`).

Net→brüt iterasyonu ve kalem bazında brütleştirme henüz yok.

## 5. Değişti mekanizması

- Hesap anında `InputSnapshot + InputHash` saklanır.
- Event güdümlü: `SalaryChanged, ProfileChanged, BankChanged, LeaveChanged, Expense.AdjustmentPosted, LegislationParameterChanged, TimesheetLineChanged, OvertimeConvertedToPay` → aktif bayrağa reason merge.
- Zamanlı: `ChangeDetectionJob` (Hangfire, 5 dk) canlı hash ≠ snapshot olanları `hash_mismatch` ile bayraklar.
- `RecalculateDirty` / `RecalculateAll`; başarılı run `ClearedByRunId` ile kapatır.
- `Approved/Paid/Locked` dönemde bayrak yazılır, hesap yapılmaz → Supplementary önerilir.

## 7. Mevzuatsal detay (özet)

- **İş K. md.37:** e-pusula zorunlu içeriği (dönem, FM/hafta tatili/bayram, vergi/SGK/avans/nafaka/icra ayrı). Eksikse İPC.
- **Ücret esası:** maktu aylıkta hastalık düşülmez; günlük/saatlikte düşülür (`WageBasis + SickDaysReducePay`).
- **Yemek:** fiili gün × günlük istisna; ayni hariç; market kartı taslakta tam matrahta — mali müşavir onayı şart.
- **Teşvik:** `IncentiveLawCode + APHB + Incentive.{Law}.*`; 5 puan indirimi kodda 0.
- **Sendika/TİS:** aidat başlangıcı bildirim sonrası ilk dönem; `SOLIDARITY_DUES`; geriye dönükte `TIS_RETRO_DIFF`; işçi lehine kural.
- **Tazminatlar:** kıdem/ihbar + işe iade 4–8 ay + ≤4 ay boşta süre (SGK+kıdem eklenir); kötü niyet ihbar×3; ayrımcılık çıplak; sendikal ≥12 ay; md.30=6 ay, md.31=3 ay; `Bare/Dressed` kalem bazında.
- **Devir (md.6):** devreden kendi dönemi × devir ücreti; ihbar devralanda; 2 yıl müteselsil.
- **Eksik gün:** `MissingDayReasons` parametrik; uzaktan çalışma bordroyu etkilemez.
- **7578 s.K. (01.05.2026):** analık 8+8 → 8+16 hafta; tarih aralıklı parametre.
- **FM:** 270 saat/yıl, yasaklı gruplar, süresiz yazılı onay, gece ayrı onay.
- **Asgari istisna:** GV + damgada türetilmiş istisna; SGK taban/tavan clamp; kümülatif dilim.

## 11. Açık noktalar

1. Bordro ekranları videoda yok — alan adları aday.
2. Market-kartı istisnası, FM çarpan listesi, net brütleştirme kapsamı doğrulanmadı.
3. Turnusol formatı / çarşaf çok-dönemliliği belirsiz.
4. Luca/Logo/Mikro formatları bilinmiyor.
5. TİS `Terms` şeması hukuk görüşü ister.
6. KEP + `Onaylıyorum` denkliği hukuk onayı ister.
7. Teşvik/gece zammı/tazminat uygulanabilirlikleri mali müşavir bekliyor.

Uçlar (TimeKpisController, `/analytics/kpis/...`, izin `attendance.dashboard.view`, kapsam IDataScopeService; from/to opsiyonel, varsayılan son 7 gün, en çok 366 gün):
- `attendance-7d` -> DailyAttendanceTotalsDto[] (okuyucu boş günleri sıfırla doldurur)
- `late-early-by-unit` -> [{orgUnitId?, orgUnitName, lateCount, lateMinutes, earlyLeaveCount, earlyLeaveMinutes}] (Department seviyesi; hepsi 0 olan birim yok; atanmamış satırı orgUnitId yok, orgUnitName "Unassigned")

Okuyucu: Attendance.Infrastructure/Lookups/AttendanceDailyKpiReader.cs (planlı = PlannedMinutes>0 veya yayınlanmış vardiya; izin = IApprovedLeaveDateLookup, opsiyonel; vardiya günü "çalışıldı" = etkin çalışılan dakika > 0). Migration yok.

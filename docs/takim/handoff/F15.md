# F15 — terminal yönetimi ekranları (web)

Durum: incelemeye hazır (web). Sözleşme T1'den ÖNCE yazıldı: T1 dalında henüz Terminal controller/DTO yok (T1 ve T2 koddan okunamadı).

## Varsayılan uç noktalar (T1 yazılınca web/src/services/attendance-terminals.service.ts'te doğrula)
- GET/POST v1/attendance/terminals; PUT {id}; POST {id}/api-key (yenile), {id}/activate|deactivate. Oluştur/yenile yanıtı `{ id, apiKey }`.
- Gruplar: v1/attendance/terminal-groups (GET/POST/PUT {id}/DELETE {id}).
- Kimlikler: GET v1/attendance/terminal-credentials?employeeId=, POST {employeeId,kind,value}, POST {id}/activate|deactivate.
  Liste DTO: `{id, employeeId, kind, lastTwo?, isActive}`. T1 değeri HMAC özetle sakladığı için `lastTwo`
  sunucu tarafında ayrıca tutulmazsa hep `••••` görünür (kabul); ham değer hiçbir yanıtta beklenmez.
- Terminal DTO: code, name, terminalGroupId?, locationId?, directionMode(both|inOnly|outOnly), isActive, lastSeenAtUtc?, online.

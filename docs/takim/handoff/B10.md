# B10 — Z3.2 plan şablonu + Excel içe aktarma

Dal `takim/B10`. Riskli alan: yok (migration yok; ShiftPlanTemplate şeması W0-a'dan).

## Uçlar (web sözleşmesi, F7 ile uyumlu)
- `GET/POST /api/v1/attendance/shift-templates` — `{name, periodLengthDays, entries[{employeeId, dayOffset, shiftDefinitionId?, dayType}]}`; POST -> şablon id (Guid).
- `POST .../{id}/apply` `{startDate, overwritePublished}` -> `{affectedCount, skipped[{employeeId, date, reason: "locked"|"published"}]}`.
- `DELETE .../{id}` (ek).
- İzin: `attendance.shifttemplate.manage` (liste dahil); çalışan kapsamı `attendance.shift.plan` veri kapsamı ile denetlenir.
- DataTransfer şablon kodu `shift-plan`: sütunlar `employeeNationalId` (eşleşme anahtarı), `date`, `shiftCode` (açılır liste: aktif tanım kodları + `WEEKLY_REST`, `REST_DAY`, `PUBLIC_HOLIDAY`). İzin `attendance.shift.plan`.

## Davranış
- Şablon yalnız atanmış hücreleri saklar; çalışma günü olmayan hücrede tanım tutulmaz, çalışma gününde tanım zorunlu.
- Apply yalnız şablondaki çalışanlara yazar; kilitli ay -> `locked`, yayınlanmış vardiya (overwrite yoksa) -> `published` atlanır. Limit/dinlenme/müsaitlik ihlali tüm uygulamayı hata ile keser (B8 toplu atamayla aynı).
- İçe aktarma satır satır: bilinmeyen kod, kilitli ay, yayınlanmış gün, limit ihlali yalnız o satırı hatalı yapar; AllOrNothing'de hiçbiri kaydedilmez.

## Notlar / endişeler
- `ShiftPlanCellWriter` (Application/ShiftTemplates) ortak hücre yazıcı; B8'in `ShiftDefinitionTimes`/`CreateDayOff` yardımcıları henüz bu dalda yok, bu yüzden kendi `ShiftTemplateTimes` ve gün-dışı satır (00:00-00:01, `SetPlan`) mantığı var. B8 birleşince `ShiftAssignment.ApplyDayOff/CreateDayOff` ile değiştirilebilir (kopya saat çözümü).
- Dinlenme günü satırı B8 birleşene dek `ShiftMinutes` = 1 dk döner (B8 non-work için 0 yapıyor).
- Testler önce uygulama yazıldıktan sonra eklendi (kırmızı adım gözlenmedi); 6 test: 4 brief testi + kilit/yayın atlama + AllOrNothing.
- DI: `IShiftPlanTemplateRepository` `AddAttendanceCoreServices` sonuna; import şablon/handler `AttendanceModule.cs` sonuna. resx tr/en 14 anahtar (`import.template.shiftplan.*`, `import.column.shiftplan.*`).

# B4 - Z1.1 gunluk liste ucu + elle okutma + Leave tarih bazli izinli sorgusu

Dal takim/B4 (taban a/zaman-devam).

## Yapilan
- `Application/Daily/DailyStatusFilter.cs`: spec 5.4 durum tablosu (tek yerde). Incalculable gun yalniz `incalculable` listesinde; `absent` = NoData ve o gun onayli izin yok; `onLeave` Leave'den (kayittan bagimsiz).
- `Application/Daily/DailyAttendanceQuery.cs`: `IDailyAttendanceQuery` uygulamasi. Kapsam = `IDataScopeService` (attendance.daily.view) + orgUnit (includeSubUnits -> `IOrgUnitLookup.GetSelfAndDescendantIdsAsync`). Liste ve sayimlar ayni siniflandirmadan; sayimlar tum durumlari icerir (0 dahil). Sayfa satirlarina `CheckInPunchId`/`CheckOutPunchId` (gunun ilk In / son Out okutmasi) doldurulur.
- `Application/Daily/DailyAttendanceFeatures.cs`: sorgu handler'lari. Counts yaniti `IReadOnlyDictionary<string,int>` (camelCase durum adi anahtarlari; enum-anahtarli sozluk serilestirme belirsizligini onlemek icin).
- `Application/Daily/DailyPunchCommands.cs`: `AddDailyPunchCommand` / `DeleteDailyPunchCommand` (attendance.punch.manage): gerekce zorunlu, veri kapsami, K6 kilidi (onayli `MonthlyTimesheetApproval` -> `AttendanceErrors.PeriodLocked`), kayit/silme `IPunchRecorder` uzerinden (denetim izi: Punch IAuditLogged + SoftDelete kim/ne zaman/gerekce).
- `Api/Controllers/DailyAttendanceController.cs`: GET daily, GET daily/counts, POST daily/punches ({id} doner), DELETE daily/punches/{id} (govde {reason}).
- Leave: `Infrastructure/Lookups/LeaveOnDateReader.cs` + `LeaveServiceCollectionExtensions` sonuna kayit. Yalniz onayli TAM GUN izinler (saatlik/yarim gun donmez); calisan basina tek satir.
- Contracts: `DailyAttendanceRowDto`'ya sona `Guid? CheckInPunchId = null, Guid? CheckOutPunchId = null`; `AttendancePermissions.DailyViewKey/PunchManageKey` sabitleri.
- resx tr/en: attendance.punch.reason_required, attendance.timesheet.period_locked, attendance.punch.not_found.
- DI: `IDailyAttendanceQuery` `AddAttendanceServices` (yalniz API) sonuna.

## Diger seritlerle dikkat (birlesme)
- `IPunchRepository`'ye yeni uye `FindAsync(tenantId, punchId)` eklendi (Domain/Repositories.cs) ve `PunchRepository`'de uygulandi (Infrastructure/Persistence/Repositories.cs). B1 ayni siniflari degistiriyorsa kucuk metin catismasi olabilir; imza sabit.
- `IPunchRecorder` uygulamasi B1'de; bu serit yalniz arayuze bagli (testlerde NSubstitute). B1 birlesmeden POST/DELETE runtime'da DI hatasi verir.
- Punch okutma silme kilidi/gun yeniden hesabi recorder'da da uygulanmali (bu serit yalniz erken ret yapar).

## Bilinen sinirlar
- `OrgUnitName` bos: Attendance calisanin birimini bilmiyor (IEmployeeDirectory'de birim alani yok). Web sutununu bos gorur.
- Elle okutmanin K6 ayi: kiracinin saat diliminde yerel tarihe gore; silmede Punch.WorkDate.
- Liste bellekte siniflandirip sayfalar (kapsamdaki calisan sayisi kadar); cok buyuk kiracilarda SQL tarafina alinabilir.

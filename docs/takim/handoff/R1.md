# R1 (Z4.1a) - zaman raporlari

Yeni saglayicilar (Attendance.Infrastructure/Reporting, kategori `time`, izin `attendance.daily.view`):
- `attendance.time.incalculable` (IncalculableReportProvider)
- `attendance.time.daily_status` (DailyStatusListsReportProvider; `status` = DailyStatus adi, camelCase)
- `attendance.time.no_shift_assigned` (NoShiftAssignedReportProvider)
Ortak: DailyStatusReportSupport (gunluk sorgudan sayfali okuma), AttendanceReportPdfExport.Produce/BuildDocument(periodText)
(R2 bunlari kullanabilir; mevcut aylik ozet/kapanis cikti degismedi).

Parametreler: `date` (tek gun) ya da from/to (en cok 31 gun; gunluk raporlar), birimler (orgUnitIds), `format=pdf`.
Vardiya atanmayanlar: from/to zorunlu (en cok 366 gun); planli gun = calisanin gecerli calisma tablosunda calisma gunu
(tarihli atama, yoksa varsayilan tablo), ise giris/cikis araliginda, hic ShiftAssignment satiri olmayan gun
(Work disi DayType satiri da bir plan karari sayilir, listelenmez).

Endiseler / acik konular:
- `status` ve `format` Parameters'ta duyurulmuyor (ReportParameterKind'da secim turu yok; web bunlari cizemez) - web/Reporting
  tarafinda `select` turu + `date` turu eklenene kadar API'den elle gonderilir. Gecersiz/eksik `status` InvalidOperationException (mevcut Resolve deseni).
- Katalogdaki tum saglayicilar cozuldugu icin AttendanceLeaveCrossCheckAndReportingTests fixture'ina IPunchRepository (TryAdd),
  ITenantTimeZoneLookup, TimeProvider, IEmployeeDirectory taklitleri eklendi. IPunchRepository kaydi takim/B1 dalinda (a/zaman-devam'da henuz yok):
  B1 birlesmeden DI'da IEnumerable<IReportProvider> cozulurse tum rapor katalogu dusebilir - B1 birlesimi sart.
- web vitest (i18n.locales.test.ts) worktree'de node_modules olmadigi icin kosulmadi; tr/en/de reports.json anahtar esitligi betikle dogrulandi.

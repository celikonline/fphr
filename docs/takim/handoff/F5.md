## B8 ile varsayılan sözleşme (backend bununla hizalanmalı)
Taban `/v1/attendance/shifts`:
- `POST bulk-assign` `{employeeIds[], dates[], shiftDefinitionId?, dayType: work|weeklyRest|restDay|publicHoliday, overwritePublished?}` -> `{affectedCount, skipped:[{employeeId,date,reason}]}`
- `POST bulk-clear` `{employeeIds[], dates[], overwritePublished?}` -> aynı sonuç. (employeeIds x dates kartezyen çarpım)
- `GET unassigned?from&to&employeeIds` -> `string[]` (çalışan id)
- `GET totals?from&to&employeeIds` -> `{byDate:[{date,employeeCount,totalMinutes}], byEmployee:[{employeeId,totalMinutes}]}`
- `GET shifts` yanıtındaki atama DTO'suna `shiftDefinitionId?` ve `dayType?` (camelCase) eklenmeli; `dayType != work` ise saatler gösterilmez.

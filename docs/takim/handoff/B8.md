Dal `takim/B8`. Riskli alan yok; migration yok.

## Uclar (`v1/attendance/shifts/...`)
- `POST bulk-assign` `{employeeIds[], dates[], shiftDefinitionId?, dayType, overwritePublished?}` -> `{affectedCount, skipped:[{employeeId,date,reason:'locked'|'published'}]}`
  - `dayType=work` -> `shiftDefinitionId` zorunlu (`attendance.shift.definition_required`), aktif tanim yoksa 404; `dayType!=work` -> tanim yok sayilir, saat tutulmaz (00:00, mola 0, sure 0, tanim bagi kalkar).
  - Kilit denetimi hucre bazinda (hucrenin kendi ayi); yayinlanmis hucre `overwritePublished` yoksa atlanir.
  - Work hucrelerinde mevcut limit (gunluk/haftalik, mola, 11 sa dinlenme) ve musait-degilim kontrolleri calisir; ihlalde tum komut hata doner (Repeat ile ayni). Limit hesabina yalniz work gunleri girer.
- `POST bulk-clear` `{employeeIds[], dates[], overwritePublished?}` -> ayni sonuc; atamasi olmayan hucre sessiz.
- `GET unassigned?from&to&employeeIds=a&employeeIds=b` -> `Guid[]`: aralikta HIC atamasi (gun turu dahil) olmayan calisanlar. employeeIds yoksa gorunur kapsam; kapsam sinirsizsa bos doner (Attendance'ta calisan listesi yok) - web her zaman grid calisanlarini gondermeli.
- `GET totals?from&to&employeeIds` -> `{byDate:[{date,employeeCount,totalMinutes}], byEmployee:[{employeeId,totalMinutes}]}`; work disi gunler 0 dk ve employeeCount'a girmez, work atamasi olmayan gun byDate'te yok.
- `GET shifts` / `me` DTO'suna `shiftDefinitionId?` ve `dayType` (her zaman; `work`, `weeklyRest`, `restDay`, `publicHoliday`) eklendi.

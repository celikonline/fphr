# B19 — E9 backend: giriş bilgisi gönderme anahtarı

- `InviteEmployeeCommand(EmployeeId, SendCredentials = true)`; `POST /invitations/employee` gövdesine `sendCredentials` (varsayılan true, eski istemciler etkilenmez).
- `false`: çalışan doğrulanır, kullanıcı/davet/e-posta yok; sonuç `Outcome = "NotRequested"`.
- `true`: mevcut akış (iş e-postası, yoksa kişisel; ikisi de yoksa `InvitationEmailRequired` kuralı). Yalnız e-posta, SMS yok (K5).
- Testler: `tests/Modules/Sense.Modules.Identity.Tests/Users/InviteEmployeeSendCredentialsTests.cs` (4). Identity testleri 247 geçti.
- Web (F14): çalışan oluşturulduktan sonra anahtar açıksa `sendCredentials: true`, kapalıysa çağrı hiç yapılmayabilir ya da false gönderilir.
- Riskli alan: src/Modules/Identity/** (davet akışı) — insan onayı gerekir.

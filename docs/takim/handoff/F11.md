## Düzeltme turu 1/5 (gözden geçirme: 3 Important + minor)
- Mobil `formatMoney(amount, currency?)`: `Intl.NumberFormat` cihaz locale'i, currency yoksa TRY (eski sabit "₺" kalktı).
- `canAcknowledge` (web + mobil): bekleyen itirazda (`pending`) pasif; `accepted`/`rejected` sonrası, daha önce onaylanmamışsa yeniden aktif. UI'da "İtirazınız inceleniyor" ipucu.
- Mobil onay sonrası yerel `new Date()` kaldırıldı: `acknowledge()` sunucu satırını döndürür; yanıtta satır yoksa liste yeniden çekilir.
- Web `MyPayslips` brüt tutarı da gösterir.

### B12'ye BAĞLAYICI SÖZLEŞME
- Liste DTO: `payslipId, year, month, grossPay, netPay, currency?, publishedAt?, acknowledgedAt?, objectionStatus? ('pending'|'accepted'|'rejected'), objectionReason?, objectionResolutionNote?`.
- `POST /v1/payroll/me/payslips/{id}/acknowledge` -> güncel satır (acknowledgedAt sunucu zamanı).
- `POST .../{id}/object` `{reason}` -> güncel satır.
- Hatalar: 409 zaten onaylı, 422 yayınlanmamış, 400 gerekçe boş; bekleyen itirazda `/acknowledge` 409.
- Karar: bekleyen itirazda onay yok; itiraz sonuçlanınca (accepted/rejected) onay yeniden mümkün.
- Kapsam dışı: bordro belgesi (PDF) indirme ayrı iş.

# B7 - Vekalet (Z2.2, Workflow)

Kapsam: `ApprovalDelegation` (Domain/Delegations), `DelegationResolver` + `DelegationFeatures` (Application/Delegations), `DelegationsController` (`v1/workflow/delegations`, mine + admin uçları), migration `AddApprovalDelegations` (tablo `workflow.approval_delegations` + `approval_tasks.decided_on_behalf_of_employee_id`), inbox/decide entegrasyonu, resx tr/en.

Kararlar
- EndDate dahil; "bugün" = UTC tarihi (`DelegationResolver.Today`). Kiracı saat dilimi kullanılmıyor.
- Zincir yok: resolver yalnız delegate'i o kişi olan vekaletleri döner.
- İptal ileriye etkili; geçmiş karar `DecidedOnBehalfOfEmployeeId` kalıcı.
- Vekil kendi talebini vekaletle onaylayamaz (SelfApprovalNotAllowed). Vekaletli inbox de bu talepleri gizler.
- Vekalet yalnız `ApproverEmployeeId`'si somut görevlerde geçerli (fallback rol kuyruğu etkilenmez).

Sapmalar / endişeler
- `ActiveDelegatorsFor` DB okuduğu için `Task<IReadOnlyList<Guid>>` döner (brief senkron yazmış); ek `CancellationToken` opsiyonel.
- E-posta karar yolu (token) değiştirilmedi: token atanan kişiye gider, vekil o token ile karar vermiyor; vekil web'den karar verir.
- `ApprovalDelegationAssigned` entegrasyon olayı Workflow.Contracts'a eklendi ve oluşturmada outbox'a yazılıyor; Notifications tarafında tüketici (`NotificationKeys.ApprovalDelegationAssigned` şablonu) başka şeritte bağlanmalı.
- Sabit imza değişikliği: `IApprovalRequestRepository.ListInboxTasksAsync` 3. parametre `delegatorEmployeeIds`; `ListInboxHandler`/`DecideApprovalTaskHandler` ctor'larına `DelegationResolver` (+ inbox'a `TimeProvider`) eklendi; mevcut testler güncellendi.

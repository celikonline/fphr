# B14 - Etkinlik zenginlestirme (E4 backend, Announcements)

## API
- `POST/PUT /api/v1/announcements/events`: mevcut alanlara ek (hepsi opsiyonel, eski istekler calisir): `startsAt`, `endsAt`, `isAllDay`, `mode` (`onsite|online`), `location`, `onlineUrl`, `notifyInvitees`, `categoryId`, `inviteeEmployeeIds`.
  - `startsAt` yoksa `eventDate` tum gun etkinlik olur. `eventDate` her zaman `startsAt`'tan turetilir. `isAllDay` verilmezse `startsAt` yoksa true, varsa false.
  - `mode=online` -> gecerli http(s) `onlineUrl` zorunlu; `mode=onsite` -> `location` zorunlu; `mode` bos -> kural yok (eski kayitlar). `endsAt < startsAt` -> `company_event.ends_before_starts`.
  - PUT'ta `inviteeEmployeeIds` null = davetlilere dokunma; liste = degistir (yalniz yeni eklenenlere bildirim).
- `GET /events/calendar`: cok gunlu etkinlikler aralikla kesisiyorsa doner; girdiye `startsAt, endsAt, isAllDay, mode, location, onlineUrl, categoryId, inviteeEmployeeIds` eklendi. `date` = baslangic gunu.
- Kategori katalogu: `GET/POST /events/categories`, `PUT/DELETE /events/categories/{categoryId}` (ad<=60, renk `#RRGGBB`; kullanimdaki kategori silinemez, ad benzersiz).

## Bildirim
- `notifyInvitees=true` ve yeni davetli varsa `CompanyEventInvitationRequested` (Announcements.Contracts.Events) outbox'a yazilir. **Notifications tarafinda bu olayi tuketen handler + sablon HENUZ YOK** (`announcement.event_invitation` anahtari/katalogu W0-b'de var; handler Notifications sahibine ayri is).

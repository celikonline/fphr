# B3 - Yeniden hesaplama servisi + oto-kilit (Z0.3, K7)

## Yapılanlar
- `Application/Recalculation`: `IDayRebuilder` (port) + `ExistingRecordDayRebuilder` (varsayılan), `RecalculationExecutor` (200'lük çalışan parçaları, parça başına tek SaveChanges; onaylı ay atlanır; Resolved/Ignored+override korunur; idempotent), `RecalculationJobStore` (bellek, tablo/migration YOK), `EnqueueRecalculationCommand`/`GetRecalculationStatusQuery` (`attendance.recalculate.run`).
- `Domain`: `AttendanceDay.RestoreResolution` (Recompute override'ı siliyor; çözüm yeniden hesap sonrası geri yüklenir; gün artık anomali taşımıyorsa yüklenmez).
- `Infrastructure/Jobs`: `AttendanceDayRecalculator` (singleton, `IAttendanceDayRecalculator`), `RecalculationHostedService` (kanal okur), `ShiftPeriodAutoLockJobHandler` (`JobType.ShiftPeriodAutoLock` -> `LockDueShiftPeriodsCommand`; tenantsiz çağrı no-op).
- `Api`: `RecalculationController` POST `v1/attendance/recalculation` -> 202 {jobId}; GET `.../{jobId}`. Kayıtlar `AttendanceServiceCollectionExtensions` (API-only, sona) ve `AttendanceModule` (sona). resx tr/en: `attendance.recalculation.{range_invalid,range_too_long,job_not_found}`.

## B1/B2 birleşince BAĞLANMASI GEREKEN yer
`IDayRebuilder` şu an `ExistingRecordDayRebuilder` (var olan günün CheckIn/CheckOut'unu yeniden planla çözer; punch okumaz, kaydı olmayan güne gün yaratmaz). B1 `DayFromPunches.Build` + B2 `PlannedDayResolver` hazır olunca punch tabanlı bir `IDayRebuilder` yazılıp `AddAttendanceServices` içindeki `AddScoped<IDayRebuilder, ...>` satırı değiştirilmeli: `IPunchRepository.ListForDayAsync` -> `DayFromPunches.Build` -> `AttendanceDayUpsert`/`UpdateRecord`; günü döndürür, punch yoksa ve kayıt yoksa null.

## Notlar
- İş durumu bellekte; yeniden başlatmada kaybolur (idempotent, yeniden kuyruklanır). Hosted service yalnız API sürecinde (IEmployeeDirectory Worker'da yok).
- `RecalculateNowAsync` küçük aralık içindir; aralık üst sınırı yalnız komut (366 gün) tarafında.
- Auto-lock "bugün" = UTC tarihi (tenant-yerel saat değil); ay kilidi günü granülaritesinde fark yaratabilir.

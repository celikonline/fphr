# ADR 0005 — Web istemcisi PWA

**Durum:** Kabul edildi — 2026-09-14

## Karar
`web/` (React 18 + Vite + TS) `vite-plugin-pwa` ile Progressive Web App olarak yayınlanır: manifest (kurulabilir), Workbox service worker (app shell precache, API NetworkFirst), offline sayfası, Web Push (VAPID), güncelleme bildirimi, QR/GPS check-in için IndexedDB offline kuyruğu (mobil uygulama ile aynı batch ucu).
